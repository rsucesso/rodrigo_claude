# Werner: Fúria Verde

Jogo de pancadaria (beat 'em up) estilo fliperama, feito de presente para os 60 anos do Werner Grau.
Werner resgata cães, salva árvores, protege pessoas e enfrenta o Barão da Motosserra para recuperar o bolo da festa.

- Jogo: `werner-game/index.html` (arquivo único, abre direto no navegador do celular, na horizontal).
- Controles no celular: direcional à esquerda, botões SOCO, PULO e LEI (especial).
- Teclado: setas para andar, J soco, K pulo, L especial, P pausa.
- Para mudar a dedicatória final, edite `DEDICATORIA` e `ASSINATURA` no topo do script.
